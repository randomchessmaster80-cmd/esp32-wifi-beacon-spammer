🛠️ Troubleshooting & FAQs
No serial port shows up when I click the button?
Make sure you are using a data cable (some micro-USB / USB-C cords only carry power, not data). Also, if your ESP32 has a BOOT button, hold it down while clicking Connect, then release it once connected.
Can I flash this using my Android phone?
Yes! Plug your ESP32 into your Android phone with a USB OTG adapter, open this page in Google Chrome for Android, and click the install button.
Can I run the spammer without a computer afterwards?
Yes! Once flashed, the ESP32 is completely standalone. You can plug it into any 5V USB wall phone charger, power bank, or car charger and it will broadcast indefinitely.
