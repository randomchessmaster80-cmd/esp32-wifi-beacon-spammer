🛠️ Frequently Asked Questions
No serial port shows up when I click Connect?
Make sure you are using a data USB cable (some cables are charge-only). If your ESP32 has a BOOT button, hold it down while clicking Connect, then release it once the browser detects it.
How does the Erase Flash tool work?
It communicates directly with the ESP32 ROM bootloader via Web Serial to execute an `erase_flash` command, resetting every block in the SPI flash memory back to `0xFF`.
Can I use this on an Android smartphone?
Yes! Connect your ESP32 using a USB-OTG adapter, open this page in Google Chrome for Android, and all tools work natively!
